# /scale — Scaling & Replication Design

## Purpose
Take a proven enterprise model and design its expansion — whether that means a single person adding a second product line, a cooperative opening in a new district, or a government replicating a successful programme nationally. This skill ensures growth doesn't destroy what works.

## Trigger
User says: /scale [description of what exists and where they want to take it]

## What This Skill Solves
- **Premature scaling** — growing before the model is proven, burning cash and credibility
- **Copy-paste failure** — assuming what works in one location will work identically in another
- **Loss of quality** — growth dilutes the product, service, or culture that made it succeed
- **Management bottleneck** — founder can't let go, becomes the constraint
- **Capital trap** — seeking big investment to scale when phased growth is possible
- **Market saturation blindness** — scaling into markets that can't absorb more supply
- **Talent gap** — no pipeline of people ready to manage new operations
- **Systems collapse** — manual processes that work for 1 location break at 3

## Doctrine Alignment
- **Asset-first**: What assets does the proven model already have that can be leveraged for expansion?
- **Revenue-before-funding**: Scale with revenue first; only seek capital when growth is constrained by proven demand, not ambition
- **Data-verified**: Scale decisions must be backed by numbers from the existing operation

## Input Required
ONE sentence minimum. Examples:
- "My phone repair shop is profitable, I want to open a second one"
- "The cooperative model works in Bolgatanga, we want to do it in Wa"
- "Government school feeding programme worked in 3 districts, scale to 50"
- "I sell online and want to expand to physical shops"

## Skill Procedure

### STEP 1 — Readiness Assessment
Before designing scale, prove the model is ready:

```
SCALE READINESS SCORECARD
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

CRITERION                                    YES/NO    EVIDENCE
─────────────────────────────────────────────────────────────────
1. Profitable for at least 6 consecutive
   months (or 2 seasons for seasonal)?
2. Revenue growing or stable (not declining)?
3. Customer satisfaction high (low complaints,
   repeat customers)?
4. Operations documented (someone else could
   follow the process)?
5. Key person dependency eliminated (runs
   without founder for 2+ weeks)?
6. Supply chain reliable (no frequent
   stockouts or quality failures)?
7. Financial records accurate and current?
8. Cash reserves cover 3+ months operating
   costs?
9. Management capacity exists or can be
   recruited?
10. Market demand confirmed in target area?
─────────────────────────────────────────────────────────────────

SCORING:
  9-10 YES: Ready to scale. Proceed.
  7-8 YES:  Almost ready. Fix gaps first (design fixes below).
  5-6 YES:  Not ready. Strengthen the base before scaling.
  < 5 YES:  Premature. Return to /execute and /diagnose.

HARD STOPS (Cannot scale regardless of score if ANY are true):
  □ Business is not yet profitable
  □ Founder must be present daily for operations to function
  □ No written processes exist
  □ Financial records are unreliable or incomplete
```

### STEP 2 — Scale Model Selection
Choose the right growth strategy:

```
SCALE MODEL OPTIONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

MODEL A: DEEPEN (Same location, more value)
┌──────────────────────────────────────────────────────┐
│ Add products / services to existing operation         │
│ Serve more customer segments at same location         │
│ Extend operating hours / seasons                      │
│ Improve margins through efficiency                    │
│                                                       │
│ BEST WHEN: Market not saturated, space available,     │
│ existing customers want more from you                 │
│ RISK LEVEL: Low                                       │
│ CAPITAL NEEDED: Minimal                               │
└──────────────────────────────────────────────────────┘

MODEL B: REPLICATE (Same model, new location)
┌──────────────────────────────────────────────────────┐
│ Open identical operation in new geography              │
│ Same products, same processes, same standards          │
│ Requires trained manager for new site                  │
│                                                       │
│ BEST WHEN: Model is proven and documented,            │
│ demand confirmed in new location                      │
│ RISK LEVEL: Medium                                    │
│ CAPITAL NEEDED: Moderate (setup costs)                │
└──────────────────────────────────────────────────────┘

MODEL C: FRANCHISE / LICENCE (Others run your model)
┌──────────────────────────────────────────────────────┐
│ Train others to run your model under your brand       │
│ Earn fees / royalties / supply margin                  │
│ You provide: brand, training, systems, supply         │
│ They provide: capital, labour, local knowledge        │
│                                                       │
│ BEST WHEN: Model is highly systematised,              │
│ your brand has value, you want speed                  │
│ RISK LEVEL: Medium-High (quality control)             │
│ CAPITAL NEEDED: Low (franchisee invests)              │
└──────────────────────────────────────────────────────┘

MODEL D: FEDERATE (Independent units, shared services)
┌──────────────────────────────────────────────────────┐
│ Multiple independent enterprises share:               │
│   - Bulk purchasing                                   │
│   - Brand / marketing                                 │
│   - Training / quality standards                      │
│   - Market access / distribution                      │
│ Each unit is locally owned and managed                 │
│                                                       │
│ BEST WHEN: Community enterprises, cooperatives,       │
│ government programmes across districts                │
│ RISK LEVEL: Medium (coordination challenge)           │
│ CAPITAL NEEDED: Low per unit                          │
└──────────────────────────────────────────────────────┘

MODEL E: INTEGRATE (Move up or down the value chain)
┌──────────────────────────────────────────────────────┐
│ Backward: Start producing your own inputs             │
│ Forward: Start processing, distributing, retailing    │
│ Captures more value from same product                 │
│                                                       │
│ BEST WHEN: Margins are thin because middlemen          │
│ capture value, or input costs are volatile            │
│ RISK LEVEL: High (new capabilities needed)            │
│ CAPITAL NEEDED: High                                  │
└──────────────────────────────────────────────────────┘

RECOMMENDED MODEL: [Based on readiness score + context]
RATIONALE: [Why this model fits the user's situation]
```

### STEP 4 — Operations Manual for Replication
The core document that makes scaling possible:

```
OPERATIONS MANUAL OUTLINE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. BUSINESS OVERVIEW
   - What the business does (one paragraph)
   - Who the customer is
   - What makes it work (the core model)

2. SETUP CHECKLIST
   - Site selection criteria (minimum requirements)
   - Equipment / asset list with specifications
   - Initial inventory requirements
   - Legal / registration steps
   - Setup budget with line items
   - Timeline from decision to opening

3. DAILY OPERATIONS
   - Opening procedures (step by step)
   - Service / production workflow
   - Quality standards with examples
   - Cash handling procedures
   - Closing procedures
   - Daily reporting template

4. PEOPLE
   - Organisation chart
   - Job descriptions for each role
   - Hiring criteria (what to look for)
   - Training programme (week by week)
   - Performance standards
   - Disciplinary process

5. FINANCIAL MANAGEMENT
   - Chart of accounts
   - Daily cash reconciliation process
   - Weekly financial review checklist
   - Monthly reporting template
   - Pricing rules (how to set and adjust prices)
   - Cost control guidelines

6. MARKETING & SALES
   - Brand guidelines (name, colours, signage)
   - Customer acquisition tactics
   - Customer retention tactics
   - Complaint handling process

7. SUPPLY CHAIN
   - Approved supplier list
   - Ordering procedures
   - Receiving and quality check process
   - Inventory management rules

8. PROBLEM SOLVING
   - Common problems and solutions (FAQ)
   - Escalation paths
   - Emergency procedures
   - When to call head office / founder
```

### STEP 6 — Phased Scale Plan with Milestones

```
SCALING TIMELINE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PHASE 0: PREPARE (Month 1-2)
┌──────────────────────────────────────────────────────┐
│ □ Document existing operations (create manual)        │
│ □ Identify and begin training manager candidate       │
│ □ Validate target market demand                       │
│ □ Secure site / location                              │
│ □ Budget and cash flow projection for expansion       │
│ GATE: Only proceed if all boxes checked               │
└──────────────────────────────────────────────────────┘

PHASE 1: PILOT (Month 3-5)
┌──────────────────────────────────────────────────────┐
│ □ Launch new operation at minimum viable scale        │
│ □ Founder on-site first 2 weeks minimum               │
│ □ Daily performance tracking against targets          │
│ □ Weekly comparison with original operation            │
│ □ Customer feedback collection                        │
│ GATE: Profitable by Month 5 or pause and diagnose     │
└──────────────────────────────────────────────────────┘

PHASE 2: STABILISE (Month 6-8)
┌──────────────────────────────────────────────────────┐
│ □ Manager running independently (founder visits only) │
│ □ Consistent quality (customer satisfaction matches    │
│   original operation)                                 │
│ □ Financial performance within 20% of projections     │
│ □ Staff fully trained and stable                      │
│ □ Supply chain reliable                               │
│ GATE: Stable for 3 months before considering next     │
│ expansion                                             │
└──────────────────────────────────────────────────────┘

PHASE 3: SYSTEMATISE (Month 9-12)
┌──────────────────────────────────────────────────────┐
│ □ Both operations running smoothly without founder    │
│ □ Central systems in place (reporting, procurement)   │
│ □ Operations manual updated with lessons learned      │
│ □ Training pipeline producing ready managers          │
│ □ Financial reserves rebuilt                          │
│ GATE: Ready for next expansion only when this phase   │
│ is fully complete                                     │
└──────────────────────────────────────────────────────┘

RULE: Never open unit N+1 until unit N is stable and
profitable. Speed kills more African businesses than
competition does.
```

## Output Format
Deliver a complete scaling blueprint with readiness scorecard, recommended model, phased plan, and financial projections. Be honest about readiness — if the enterprise isn't ready, say so and prescribe what to fix first.

## Connects To
- `/diagnose` — identifies issues that must be fixed before scaling
- `/solve` — original business design that's being scaled
- `/execute` — daily tracking for new operations
- `/supply-chain` — supply chain design for new locations
- `/stakeholder-map` — new locations need fresh stakeholder analysis
- `/financial-model` — multi-unit financial projections
- `/hiring` — talent pipeline for expansion
- `/legal-setup` — registration requirements in new jurisdictions

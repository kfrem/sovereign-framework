# /execute — Implementation Tracking, Monitoring & Accountability Engine

## Purpose
The skill that turns plans into results. Produces day-by-day action calendars, monitoring dashboards, accountability protocols, cash tracking systems, and anti-corruption safeguards. This skill is MANDATORY for every solution the framework produces. No plan leaves this consultancy without an execution engine attached.

## Trigger
User says: /execute [description of what needs to be implemented]
Also triggered automatically by `/solve` at the end of every solution.

## What This Skill Solves
- **Plans that sit in drawers** — beautiful strategies with no daily actions
- **No accountability** — nobody tracking whether tasks are done
- **Cash leakage** — money flowing in and out with no reconciliation
- **Corruption opportunities** — no transparency in operations, procurement, or finance
- **Management chaos** — everyone busy, nothing accomplished
- **No early warning** — problems discovered too late to fix

## Doctrine Alignment
- **Execution over Strategy** — this skill IS the doctrine
- **Ethical by Design** — anti-corruption protocols built in, not optional

## Input Required
A plan, business design, or programme from any other skill. If used standalone, a description of what needs to be executed.

```

│ Opening cash balance:          ___                    │
│ + Cash sales today:            ___                    │

│ + Other income:                ___                    │

│ ═══════════════════════════════════                   │
│ EXPECTED closing balance:      ___                    │
│ ACTUAL closing balance:        ___                    │
│ VARIANCE:                      ___                    │
│                                                       │
│ Variance < 1%: Record and file                       │
│ Variance 1-3%: Investigate before leaving            │
│ Variance > 3%: STOP — full recount, check all        │
│   receipts, do not leave until resolved              │
│ Variance > 5%: Report to owner/board immediately     │
│                                                       │
│ SIGNED BY:                                            │
│ Cash handler: _____________ Date: ___                │
│ Supervisor:   _____________ Date: ___                │
│ (Both must sign. No exceptions.)                     │
└──────────────────────────────────────────────────────┘

PROCUREMENT TRANSPARENCY PROTOCOL
┌──────────────────────────────────────────────────────┐
│ For ANY purchase above [threshold]:                   │
│   □ Get 3 quotes (written, dated, signed)            │
│   □ Select based on documented criteria              │
│   □ Get receipt for every payment                    │
│   □ Record in purchase register                      │
│   □ Physical goods verified by someone OTHER         │
│     than the purchaser (separation of duties)        │
│                                                       │
│ NEVER:                                                │
│   □ One person authorises AND pays AND receives      │
│   □ Cash payments without receipts                   │
│   □ Purchases from family/friends without            │
│     competitive quotes                               │
│   □ Advances without written authorisation           │
│   □ Petty cash without log and reconciliation        │
└──────────────────────────────────────────────────────┘

ANTI-CORRUPTION RED FLAGS
┌──────────────────────────────────────────────────────┐
│ Investigate immediately if:                           │
│   □ Same supplier wins every order                   │
│   □ Prices consistently above market rate            │
│   □ Cash variances recurring                         │
│   □ Staff lifestyle exceeds salary                   │
│   □ Records go "missing"                             │
│   □ Resistance to audits or spot checks              │
│   □ Inventory shrinkage above 2%                     │
│   □ Customers complain about being overcharged       │
│   □ Supplier relationships are personal, not         │
│     professional                                     │
│   □ Financial reports consistently late              │
```

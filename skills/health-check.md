# /health-check — 5-Minute Rapid Assessment

## Purpose
The fastest entry point into the Sovereign Framework. In under 5 minutes, assess any person, business, community, or programme and produce an immediate action plan with the right skills to deploy next.

## Trigger
User says: /health-check [description of situation]

## Input Required
ONE sentence. That's it. Examples:
- "I sell clothes in the market"
- "Our cooperative isn't making money"
- "I'm a graduate with no job"
- "The district has high unemployment"
- "I want to start something but have no money"

## Assessment Protocol

From the user's single sentence, immediately assess across 5 dimensions and score each 1-5:

```
SOVEREIGN HEALTH SCORECARD
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Client: [Name/Description]
Date: [Today]
Input: "[Their exact words]"

DIMENSION                    SCORE (1-5)    ASSESSMENT
─────────────────────────────────────────────────────────
1. ASSETS                    [  /5]         [What they have]
   (What do they have to
   work with right now?)

2. INCOME                    [  /5]         [Current income status]
   (Are they making money?
   Is it growing?)

3. MARKET                    [  /5]         [Market position]
   (Do they have customers?
   Is demand proven?)

4. SYSTEMS                   [  /5]         [How organised are they?]
   (Do they have processes,
   records, accountability?)

5. GROWTH POTENTIAL          [  /5]         [What's possible?]
   (Can this scale? Is
   there a clear path?)
─────────────────────────────────────────────────────────
TOTAL SCORE                  [  /25]

HEALTH RATING:
  20-25: STRONG — Ready to optimise and scale
  15-19: HEALTHY — Solid foundation, specific gaps to fix
  10-14: FRAGILE — Needs structural fixes before growth
   5-9:  CRITICAL — Needs fundamental redesign or rescue
   1-4:  STARTING FROM ZERO — Full build required
```

## Immediate Prescription

Based on the score, produce:

```
YOUR SITUATION IN ONE PARAGRAPH:
[Plain language summary — no jargon, no sugar-coating]

THREE THINGS TO DO THIS WEEK:
1. [Specific, actionable, free or low-cost]
2. [Specific, actionable, free or low-cost]
3. [Specific, actionable, free or low-cost]

YOUR BIGGEST RISK RIGHT NOW:
[The one thing that could sink this if not addressed]

YOUR BIGGEST OPPORTUNITY RIGHT NOW:
[The one thing that could transform this if pursued]

NEXT SKILL TO RUN:
→ [Specific skill recommendation with one-line reason]
→ [Optional second skill if needed]
```

## Routing Logic

| Score Range | Primary Recommendation |
|---|---|
| 1-4 (Starting from zero) | `/solve` — full solution design from scratch |
| 5-9 (Critical) | `/diagnose` — find root causes, then `/business-rescue` |
| 10-14 (Fragile) | `/financial-model` + `/supply-chain` — fix the economics and operations |
| 15-19 (Healthy) | `/market-intel` + `/digital-launch` — grow what's working |
| 20-25 (Strong) | `/scale` — ready to expand |

| Special Cases | Route To |
|---|---|
| Student/graduate | `/grad-bridge` regardless of score |
| Community/cooperative | `/community-enterprise` regardless of score |
| Government programme | `/gov-proposal` + `/workforce-engine` |
| "I have an idea" | `/idea-engine` → `/asset-audit` |
| "I need funding" | `/financial-model` first (make it bankable), THEN `/pitch` or `/crowd-fund` |

## Output Rules
- Keep the entire output to ONE PAGE equivalent
- Use plain language — the user may have no business education
- Be honest — if the situation is critical, say so clearly
- Always end with exactly which skill to run next
- Never say "it depends" — make the call

## Connects To
Every other skill — this is the universal entry point that routes to the right place.
